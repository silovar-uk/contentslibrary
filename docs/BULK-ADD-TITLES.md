# タイトルをまとめて追加

## 目的

作品を1件ずつ追加する手間を減らし、思い出したタイトルや購入候補を10件程度まとめて登録できるようにする。

大量データ移行を扱う「データ取込センター」とは分け、普段使いの追加操作として提供する。

## 操作

- デスクトップ: 上部の「まとめて追加」
- モバイル: 通常の「追加」を開き、「複数タイトルをまとめて追加」
- 1行につき1タイトル
- 1回につき最大10件
- 種別と状態は入力したタイトルすべてに共通で適用
- `Ctrl / Cmd + Enter`でも追加を開始可能

## 重複の扱い

入力中の同名タイトルは2件目以降を除外する。

現在のライブラリに、同じ種別かつ同名の作品がある場合も初期状態では除外する。別版・再登録など意図的に追加するときだけ、「同じ種別の同名作品も追加する」を有効にする。

比較には表示上の文字列ではなく、NFKC正規化・小文字化など既存検索と同じ正規化処理を使う。

## 失敗時

登録は既存の `POST /api/works` を1件ずつ最大10回実行する。

- 進捗を `追加中 x / n` で表示
- 成功した行は「追加済み」に変更
- 一部だけ失敗した場合、成功済み作品は保持
- 入力欄には失敗したタイトルだけを残し、そのまま再試行可能
- 入力内容はローカル下書きとして保持

## 設計判断

新しい一括登録APIやDBマイグレーションは作らない。10件という小さな単位では、既存の作品作成APIを再利用したほうが、入力検証・監査ログ・権限確認を二重実装せずに済む。

一括処理を完全なトランザクションにはしない。途中失敗時に全件を巻き戻すより、成功・失敗を作品ごとに示し、失敗分だけ再試行できる運用を優先する。
